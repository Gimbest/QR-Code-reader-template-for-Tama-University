# QR Code reader template for Tama University
## Description
This project is, as it's title says, a QR Code reader project template in Mixed Reality. It was made for the students of Tama University, but can be used by anyone that needs it.
## Dependancies
This project is meant to work on Meta Quest 3 and 3s. As such, we use the following Meta Quest Libraries on Unity :   
  
Meta XR Core SDK  
Meta MR Utility Kit
